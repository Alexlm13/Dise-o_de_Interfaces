### Fase 10. Preguntas finales

##### Explica lo que has aprendido

**1. ¿Qué diferencia existe entre un atributo HTML y una pseudoclase CSS?**   
   - En html define una característica del elemento y en CSS selecciona un elemento segun su estado.

**2. ¿En qué se diferencian :enabled y :disabled?**
   - Enabled sirve para los que están activados y disabled para los desactivados.

**3. ¿Para qué sirve :hover?**
   - Para que cada vez que pases el cursor por encima se marque.

**4. ¿Cuál es la diferencia entre :hover y :focus?**
   - hover para cuando pasas el cursor y focus para cuando usas el tabulador y lo marcas.

**5. ¿Puede recibir el foco el campo edad si está deshabilitado? Explica tu respuesta.**
   - No porque no se puede interactuar.

**6. ¿Para qué sirve :checked?**
   - Selecciona a los que están marcados.

**7. ¿Por qué los botones Hombre y Mujer deben compartir el atributo name?**
   - Para que estén en grupo y se pueda marcar uno y no ambos.

**8. ¿Cómo consigue CSS cambiar el texto de una etiqueta cuando se marca su control?**
